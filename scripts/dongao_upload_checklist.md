## 六、天气与潮汐自动刷新

`cloudfunctions/dongaoRefreshData` 负责定时刷新：

- `dongao-data/weather.json`：华风爱科开放 API，逐小时天气预报。
- `dongao-data/tide.json`：国家海洋信息中心潮汐数据。

天气源不再抓取 `tianqi.eastday.com` 页面，避免云函数环境触发 403。

部署前在微信云开发控制台给 `dongaoRefreshData` 配置环境变量：

| 变量名 | 必填 | 说明 |
|---|---|---|
| `WEATHERCN_API_KEY` | 是 | 华风爱科开放平台 API Key |
| `WEATHERCN_LOCATION_KEY` | 否 | 东澳岛对应 location key；不填时云函数会用东澳岛经纬度通过 GeoPosition 查询 |
| `WEATHERCN_API_HOST` | 否 | 默认 `openapi.weathercn.com` |
| `WEATHERCN_LANGUAGE` | 否 | 默认 `zh-cn` |
| `DONGAO_LATITUDE` / `DONGAO_LONGITUDE` | 否 | 默认使用东澳岛 GCJ-02 坐标，和小程序/高德坐标体系一致 |
| `DONGAO_COORDINATE_SYSTEM` | 否 | 默认 `gcj02`；如果传入 WGS84 坐标，设为 `wgs84`，云函数会转 GCJ-02 后调华风爱科定位 |

定时触发器在 `cloudfunctions/dongaoRefreshData/config.json` 中配置为：

```json
{
  "triggers": [
    {
      "name": "dongaoRefreshTrigger",
      "type": "timer",
      "config": "0 0 */3 * * * *"
    }
  ]
}
```

部署后可在东澳岛页面开发工具里点击“测试爬虫”。成功时日志应显示 `weather=OK 24h`，失败时会返回 `missing_weathercn_api_key`、`weathercn_api_unauthorized` 或 `weathercn_hourly_no_data` 等明确原因。
