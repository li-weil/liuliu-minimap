# 校园导览版（中山大学珠海校区）数据语料

> 状态：**第四版——点位清单最终版（含坐标）**。点位全部来自高德 POI（GCJ-02），可按此进入攻略整理阶段。
> 定位：与东澳岛完全隔离的独立模块，最终拆分为独立小程序。

## 一、项目口径

- 服务对象：中山大学珠海校区新生（校园导览）。
- 主题：`美食` / `历史` / `景点` 三选一；同一地点可打多个主题标签。
- 生成链路：选主题 → 根据当前位置 + 时间（重点是**场馆开放时间**）→ 生成任务地点 + 任务内容（或美食推荐）。
- 地点排序：距离优先（同东澳岛 `geoNear`），但先按主题过滤地点。
- 数据：预先存一份地点数据 + 攻略数据，AI 生成时读取（同东澳岛模式）。
- 范围：**严格校内**（首版不含唐家湾/鸡山村周边）。
- 入口：**tabBar 加第三页**「校园导览」，与东澳岛并存。
- 点位粒度：按楼群组团拆分。
- 隔离要求：与东澳岛代码、云函数、数据库集合、云存储目录、文档全部隔离。

## 二、点位选取规则（已确认）

1. **只保留高德有 POI 的地点**。高德无 POI 的不纳入点位（已剔除：珠海校区陈列厅、岁月湖餐厅、凤凰山天琴台、校门等）。
2. **公共教学楼**（教学实验大楼）无独立 POI，高德以「中山大学(珠海校区)」主 POI（`113.589084,22.346185`）代表教学楼核心区。通过高德联想接口确认教学楼有 **A/B/C/D/E/F 六个分区 POI**（南北走向，A 区最南、F 区最北），全部作为子点位（`group: '公共教学楼'`），坐标为高德 POI 确认值。
3. **若海餐厅**高德标记「暂停营业」，属假期营业调整，保留点位，开放时间归入 `openHours` 字段处理。
4. **开放时间**：优先找官方口径/接口；找不到就留空，视为一直开放。
5. **美食主题**纳入校内咖啡饮品店（瑞幸教学楼店/荔园店、满忆糖水教学楼店/槿园店）。
6. 用途不明且联网无法确认的地点（如瀚林楼），保留点位但不写入不确定内容。

## 三、数据结构设计（对齐东澳岛）

### 3.1 地点集合（对应东澳岛 `spots` 集合）

东澳岛字段：`map_name` / `amap_name` / `coords` / `location`

校园版新增字段：

| 字段 | 类型 | 说明 |
|---|---|---|
| `map_name` | string | 地点名（唯一，AI 生成与推荐用） |
| `amap_name` | string | 高德 POI 名（可空） |
| `coords` | string | `"经度,纬度"`，GCJ-02 |
| `location` | Geo.Point | 用于 `geoNear` 距离推荐 |
| `tags` | string[] | 主题标签，取值 `美食` / `历史` / `景点`，可多个 |
| `category` | string | 分类：`餐饮` / `建筑` / `场馆` / `自然` / `运动` / `纪念` |
| `group` | string | 归属整体点位（可空）。多区段点位（如教学楼A-E区）用同一 `group: '公共教学楼'` 归组，展示与 AI 提示时按整体处理 |
| `openHours` | string | 开放时间文本（AI 生成的时间判断依据；留空视为一直开放） |
| `intro` | string | 一句话简介（推荐列表展示用） |

### 3.2 攻略 JSON（对应东澳岛 `dongao-content/{map_name}.json`）

东澳岛攻略字段：`task1_environment`（`physical_features` / `nearby_environment` / `atmosphere`）、`task3_sensory_play`（`色` / `声` / `形` / `味`）

校园版保留上述字段，新增：

| 字段 | 说明 |
|---|---|
| `description` | 地点详细介绍（官方/攻略整理） |
| `openHours` | 场馆开放时间（如 `10:00-17:00`，周一闭馆等；无官方口径留空） |
| `themeTips` | 按主题给 AI 的素材提示：`美食`（招牌菜/推荐）、`历史`（故事/意义）、`景点`（看点/玩法） |
