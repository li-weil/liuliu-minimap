# 校园导览版（中山大学珠海校区）部署说明

> 与东澳岛完全隔离的独立模块。数据与代码均使用 `campus` 前缀命名。

## 一、新增文件清单

### 前端

| 文件 | 说明 |
|---|---|
| `miniprogram/pages/campus/campus.js` | 页面逻辑：主题选择 → 定位 → 按主题推荐点位 → 生成任务卡 → 开始漫步 |
| `miniprogram/pages/campus/campus.wxml` | 页面结构（位置面板 + 主题选择面板 + 任务卡） |
| `miniprogram/pages/campus/campus.wxss` | 样式（复用东澳岛视觉体系 + 主题 chip 样式，色板一致） |
| `miniprogram/pages/campus/campus.json` | 页面配置 |
| `miniprogram/services/campus.js` | `recommendSpots(lat, lng, tag)` / `generateMission(mapName, tag)` |
| `miniprogram/services/api.js` | 新增 `campusRecommend` / `campusGenerate` 端点（云函数模式） |
| `miniprogram/app.json` | 注册页面 + tabBar 第三页「校园导览」 |
| `miniprogram/pages/walk-detail/walk-detail.js` | 模式标签增加「校园导览模式」（walkMode `campus`） |

### 云函数（3 个）

| 云函数 | 说明 |
|---|---|
| `cloudfunctions/campusRecommend/` | 按主题过滤 + 距离排序推荐点位（`campusSpots` 集合 `geoNear`） |
| `cloudfunctions/campusGenerate/` | 读攻略（云存储 `campus-content/{map_name}.json`）→ 判断开放时间 → AI 生成任务（`campusCards` 落库） |
| `cloudfunctions/initCampusSpots/` | 初始化 `campusSpots` 集合（29 个点位）+ 地理位置索引 |

## 二、部署步骤

1. **云函数部署**：在微信开发者工具中右键上述 3 个云函数目录 → 上传并部署（云端安装依赖）。
2. **云存储上传**：把 `campus-data/content/` 下 29 个攻略 JSON 上传到云存储 `campus-content/` 目录（文件名与 `map_name` 一致）。
3. **初始化集合**：进入「校园导览」页 → 开发工具 →「初始化点位」（调用 `initCampusSpots`，创建 `campusSpots` + geo 索引；失败时按提示在云开发控制台手动建索引）。
4. **AI 配置**：给 `campusGenerate` 配置环境变量：
   - `DEEPSEEK_API_KEY`（必填，模型密钥；兼容旧变量 `AI_API_KEY`）
   - 可选：`DEEPSEEK_BASE_URL` / `DEEPSEEK_CHAT_MODEL`（默认 DeepSeek `deepseek-v4-flash`）
5. **验证**：页面「开发工具」→「测试推荐」确认推荐列表；再正常走一遍 主题选择 → 定位 → 生成 主流程。

## 三、主流程

1. **选择主题**：美食 / 历史 / 景点（三选一，页面顶部 chip）。
2. **定位**：真实 GPS 或「模拟位置」（29 个点位）。
3. **推荐**：`campusRecommend` 按主题标签过滤 `campusSpots`，距离优先。
4. **生成**：`campusGenerate` 读攻略（环境/五感/主题素材/开放时间）→ AI 生成 `mission` / `tips` / `safetyNote`。
5. **开始漫步**：写入 walkDraft（`walkMode: 'campus'`）→ 进入记录页。

## 五、已知说明

- `campusGenerate` 的攻略云存储路径沿用东澳岛方式硬编码环境 ID（`cloud1-2gdui7md5af99e5c...`），若切换环境需同步修改。
- 足迹页将校园导览记录归入「单人」类型（与东澳岛分开统计）。
- 教学楼 A-F 区共享 `group: '公共教学楼'`，推荐时按最近分区返回。
